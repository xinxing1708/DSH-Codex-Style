# DSH Codex Style

为 **DeepSeek Harness（DSH）** 提供 Codex 桌面端风格的深色界面。当前版本 **0.1.4**，npm 包名 **`@xinxing1708/dsh-codex-style`**，同一构建适配 **Windows DSH 0.2.1-rc.2 / 0.2.1-rc.3**。

本项目为社区独立插件，与 OpenAI 或 DeepSeek 无关联，未获其赞助或背书。

## 下载与安装

需要 **Node.js 20 或更高版本**。0.1.4 支持 DSH `0.2.1-rc.2` 和 `0.2.1-rc.3`；可下载 [GitHub Release 的 Windows ZIP](https://github.com/xinxing1708/DSH-Codex-Style/releases/tag/v0.1.4)，解压后直接运行安装入口。宿主版本声明为根级 `engines.dsh: "0.2.1-rc.2 || 0.2.1-rc.3"`，未声明兼容其他版本。

以下为 0.1.4 的 npm 下载步骤。若此前通过本项目脚本安装，请继续使用脚本方式升级，避免同时保留新旧名称。发布版本也可通过 DSH 的「自定义 → 插件 → 添加插件」输入完整 npm 包名安装。

在空目录的 PowerShell 中下载并解压 npm 包：

```powershell
npm pack @xinxing1708/dsh-codex-style@0.1.4 --registry=https://registry.npmmirror.com
tar -xf xinxing1708-dsh-codex-style-0.1.4.tgz
cd package
```

国内镜像同步需要时间；若提示包尚不存在，可将 registry 换成 `https://registry.npmjs.org` 重试。

1. 退出 DSH。
2. 双击 `install.cmd`，或在解压目录运行：

   ```powershell
   node scripts/install.mjs
   ```

3. 安装成功后启动 DSH。

安装器自动核对 DSH 版本，备份 desktop profile 的三份配置，安装插件并输出回退脚本位置。无需管理员权限、无需构建或安装 npm 依赖。已有全局主题会按安装规则停用，安装文件保留；升级本插件时保留上一版本。

DSH 安装在自定义位置时，在同一个 PowerShell 窗口设置现有 DSH 数据根目录，再运行安装：

```powershell
$env:DSH_HOME = "你的 DSH 数据根目录"
node scripts/install.mjs
```

默认数据根目录为当前用户的 `.dsh`，应包含 `profiles/desktop`。安装器优先检查官方 Windows 的当前用户/全局默认程序目录，再检查旧版 `dsh-runtimes` 数据目录；没有 `pnpm-lock.yaml` 的 profile 会保持无锁文件状态。

若 DSH 程序安装在其他位置，可显式指定现有 `runtime.json` 的完整路径（仍会核对版本，不会修改运行时）：

```powershell
$env:DSH_RUNTIME_FILE = "D:\Apps\DeepSeek Harness\resources\runtime\primary-runtime\runtime.json"
node scripts/install.mjs
```

## 功能

- 52px 常驻导航：首页、定时任务、自定义；社区快捷入口沿用宿主原按钮与图标。
- rc.3 的「更多」位于自定义下方、社区快捷方式上方，纯图标配悬停标签；点击展开统一二级侧栏，收起后悬停显示同款浮卡。浏览进入宿主插件列表，创建准备未发送的创造模式草稿。
- 默认 288px 的可拖动、可收起二级侧栏，收起后悬停显示浮卡。
- 真实项目和会话树，包含标题/项目过滤、置顶、重命名、分叉、归档与恢复。
- 项目分组和单项目平滑展开/收起；聊天右键及 Shift+F10 复用原菜单。
- 溢出标题悬停后以约 30 CSS px/s 匀速往返，轻微溢出与较长标题速度相同；聊天行尾提供带渐变文字提示的置顶/归档图标，已置顶显示实心图钉。
- 会话在 DSH 窗口失焦、查看其他会话或插件页面时结束，行尾显示蓝色未读完成圆点；聚焦并回到该会话后清除，当前正在查看的会话正常完成时不提醒。完成状态跟随当前插件页面，悬停行尾时让位于快捷操作。
- 运行中的会话行尾显示灰色转圈，按参考 GIF 约 1.9 秒一圈；等待处理时保留等待提示，任务结束时停止转动并按未读规则显示蓝点。减少动效设置下圆环保持静止。
- 新聊天、项目悬停详情和项目编辑。
- 齿轮账号/设置菜单，设置提示渐显渐隐。
- 单行搜索框保持 32px；发送按钮在空输入时为灰色，有内容时为灰白色。
- 输入卡按参考校准为最大 736px 宽、单行 98px 高、24px 圆角；空态、发送前、运行中和停止后尺寸与中线保持一致，多行内容仍自然增高，窄窗口自动收窄。项目选择栏只在对话开始前显示。
- 发送、排队、插话和停止按钮统一为 28px，内部图标 14px，切换动作不再改变输入卡高度。
- 停止生成按钮采用 28px 浅灰圆底和深灰方块，悬停保持灰色；点击及连续两次 Esc 沿用宿主停止动作。
- 真实权限预设、模型目录、思考强度滑条及 Max 动效。
- 保留 DSH 原生输入编辑器、附件、“+”、消息、工具调用与审批流程。
- 本插件详情页在「卸载」左侧提供真实「检查更新」按钮，可查看当前版本、最新版本和查询结果。

项目移除、会话归档和权限切换等控件使用宿主真实动作。模型切换沿用 DSH 的默认值保存行为，实际可用档位由模型目录决定。

## 可选工作规范组件

打开「自定义 → 插件 → 本插件详情 → 包含的组件」，可独立开启或关闭「Codex 风格工作规范（可选）」。组件默认关闭，与界面组件分别管理。

开启后，通过 DSH 的系统提示词扩展接口加入随包提供的 `prompts/work-guidelines.md`，引导 DeepSeek 采用接近 GPT/Codex 的工作与表达习惯：明确当前任务和授权边界，减少自由发挥、顺手改动及无关扩展；区分只读审查与执行修改；持续用简体中文正文报告进度；按证据说明结果。此组件提供提示词引导，实际效果取决于模型遵循，不更换模型或修改工具、权限、沙箱。

开关按宿主的应用/重启提示生效，控制后续模型请求中的本组件提示词，不能撤回已发送到模型的历史内容，正在进行的请求也不会被中断。已有对话需要切换规则时，建议新建对话。原有全局或项目 `AGENTS.md` 仍按 DSH 的规则独立生效；关闭此组件不会停用这些文件，也不会改写其内容。本组件不发起模型请求。

## 可选正文效果组件

在「自定义 → 插件 → 本插件详情 → 包含的组件」开启「Codex 正文效果（可选）」。默认关闭，需要同时启用界面组件；与工作规范提示词分别开关。按宿主的应用或重启提示生效。

开启后，本轮正文上方显示「已处理」真实耗时和分割线，替代底部的「深度求索中」。计时来自 DSH 的回合开始/结束时间，完成时停止；缺少时间记录时仅显示「已处理」，停止和出错会保留状态说明。当前运行步骤采用灰色流动高光，步骤展开增加轻微淡入动效，编辑文件和运行命令分别使用自绘铅笔和终端图标。实时思考正文与摘要隐藏，完成的思考项继续用 DSH 原图标展开查看。

正文、命令、文件路径、工具结果和审批仍由宿主提供，不使用演示录像中的命令或模拟步骤。关闭后移除本组件的样式和计时行，恢复原正文呈现，不改变会话记录、模型、工具与工作规范提示词。减少动效设置下关闭新增光效和展开动画。

## 检查更新

打开「自定义 → 插件 → 本插件详情」，点击「检查更新」。检查只读取 npm 版本信息，不安装或卸载插件。只有本插件的已安装包详情显示该入口，组件子页与其他插件不显示。

插件加载约 8 秒后自动查询，此后每 24 小时复查；查询结果保存在本地，重新打开不会重复查询。发现新版时在右下角提醒，点击「查看更新」进入本插件详情。关闭提醒会记住本次版本，下一个新版仍会提醒。查询失败时安静等待约 1 小时再试，恢复联网后可提前重试；手动按钮始终可用。

查询并行使用 npmmirror、腾讯云 npm 镜像和 npm 官方源，按有效响应中的最高版本提示；不依赖 GitHub，也不需要登录 npm。请求不携带凭据，最长等待约 6.5 秒；所有源失败、包未发布和最新版分别提示，不将错误当成已更新。镜像可能同步延迟，结果中会注明来源。停用插件会取消检查与定时器。

国内镜像为大陆直连用户提供更新查询通道；可用性仍取决于用户网络和镜像服务，无法保证所有运营商、所有时刻均可达。自动检查负责提醒，安装仍由用户按本页说明执行。

## 回退或卸载

退出 DSH，运行安装器输出的回退脚本：

```powershell
node "<备份目录>/rollback.mjs"
```

初装时恢复安装前配置并解除插件链接；升级时恢复上一版本。若安装后的配置有其他修改，脚本会停止并提示合并。备份和插件版本目录保留，回退后重新启动 DSH。

## 从源码构建

下载仓库源码或克隆本仓库，在根目录运行：

```powershell
npm run build
```

构建仅使用 Node.js 标准库，不需要 `npm install` 或联网。所需源码、样式、自绘图标和品牌图均已包含，产物写入 `lib/`。随后可运行 `node scripts/install.mjs`。

| 路径 | 用途 |
|---|---|
| `src/` | 客户端组件、宿主入口及局部样式 |
| `assets/` | 独立构建所需令牌、导航样式、图标及品牌图 |
| `lib/` | 可安装的构建产物 |
| `scripts/` | 构建、安装及回退 |
| `cordis.patch.yml` / `skin.json` | DSH 插件接入及皮肤元数据 |
